# Spellbook spell export

This folder contains a portable JSON export of the spell database used by Spellbook.

## Files
- spellbook_spells.json: a shareable export containing spell records and metadata

## Suggested use
- Import into another app or website as a JSON feed
- Use as a backup of the spell content without including user-specific files
- Map the fields into your own schema if needed

## Notes
- The export is based on the current Spellbook SQLite schema and spell model
- It does not include character sheets, settings, or themes
- If you plan to redistribute content publicly, make sure licensing and provenance are clear
