Added the Rules collection: the Free Basic Rules (2024) as searchable pages that other content can link to

Added the Homebrew Studio game tool: write homebrew with reference panels beside it, find existing content that does the same thing and check a monster's numbers against its CR

The monster editor now works out proficiency, hit die, hit points, saves, skills and attacks from the stats (hover a number to see why) and has folding sections; the class and subclass editors have a section ready for every level; the Add buttons on the collection pages open the Homebrew Studio (a setting, on by default)

Studio Insights are stricter: at least 4 matching words, exact matches hidden, unofficial content only when its box is ticked, and anything matching more than 10 things is left out as standard wording (all adjustable in Settings > Loading Options)

Character sheets: AC, hit points, initiative, spell attack and save DC can be hovered to see how they were worked out and typed over by hand, bonuses from magic items, features, feats and species traits are found automatically, and the equipment, magic item and feat pickers have a green Add button on every row

New Select mode on the collection lists: tick many entries, then add them all to a character, or edit their tags, classes (spells) and source in one go

Every collection search now has a "Titles only" option

Importing several files at once now finishes with a second look: mentions of content that arrived in a later file are linked, and subclasses whose class arrived later are added

Code optimization: the collections, editors, text importers and database code now share one set of building blocks instead of separate copies (about 3,600 fewer lines). Everything looks and works the same, with small fixes: a newly added or edited entry is now selected in the list, Settings > Reset to defaults resets every control, and spell tags sort ignoring capital letters
